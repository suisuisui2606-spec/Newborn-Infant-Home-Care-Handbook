# 新生儿与婴幼儿家庭照护手册

**Newborn & Infant Home Care Handbook**

本项目整理了家庭产后护理、新生儿与 2-12 个月婴幼儿喂养照护、异常情况就医提示等家庭照护资料。内容以中文为权威工作版本，README 和各文档首页提供英文标题与摘要，方便 GitHub 浏览、检索和后续协作。

This repository organizes practical family-care documents for postpartum recovery, newborn care, infant feeding from 2 to 12 months, and medical warning signs. Chinese is the authoritative working version. English titles and summaries are provided for GitHub navigation, search, and collaboration.

## 使用建议 / Suggested Use

中文：建议把本项目作为家庭内部照护协作手册使用。日常执行时，以家庭记录、儿保医生建议和当地医疗流程为准；遇到呼吸困难、意识异常、抽搐、明显脱水、严重过敏、误服危险物、头部外伤异常等情况，应优先急诊或拨打当地急救电话。

English: This repository is intended as a family coordination handbook. Daily care should follow household records, pediatric guidance, and local medical procedures. For urgent symptoms such as breathing difficulty, altered consciousness, seizure-like episodes, significant dehydration, severe allergy, ingestion of dangerous substances, or concerning head injury symptoms, seek emergency care immediately.

## 中英文版本策略 / Bilingual Strategy

中文：当前推荐采用“中文权威正文 + 英文标题与摘要”的形式。照护类内容涉及医学与本地流程，逐段英文翻译容易产生细节偏差；如果未来计划公开给英文读者使用，再单独制作经人工审核的中英文对照版。

English: The recommended structure is “authoritative Chinese content plus English titles and summaries.” Care guidance can involve medical nuance and local procedures, so full paragraph-by-paragraph translation should be reviewed carefully before being published for English-speaking readers.

## 免责声明 / Disclaimer

中文：本项目仅用于家庭照护记录、沟通和风险识别，不构成医学诊断或治疗建议。如与医生个体化建议不一致，以医生意见为准。

English: This repository is for family care coordination, record keeping, and risk recognition only. It is not a substitute for medical diagnosis or treatment. When it differs from individualized clinical advice, follow the clinician’s guidance.
